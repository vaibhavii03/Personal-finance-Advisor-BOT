Data Security & Privacy

Engineered with Privacy and Security First

Financial information is confidential. We follow robust web application security practices:

  • Secure Password Hashing: User credentials are protected using industry-standard Werkzeug scrypt hashing algorithms.
  • Protected Environment Variables: All API keys and secrets are loaded via environment variables and never hard-coded.
  • Isolated User Records: Session-based authentication ensures users can only access and modify their own financial records.

100% Protected Data

No third-party tracking, no payment card storage, and clean sandboxed SQLite storage.
